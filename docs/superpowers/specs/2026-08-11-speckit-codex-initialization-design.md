# Speckit Codex 初始化设计

## 目标

为当前空 Git 仓库建立最小的 Speckit 工作流，使 Codex 可以从规格到计划再到可执行任务进行拆解。

## 范围

- 仅生成 Speckit 的 Codex 集成、命令和规范模板。
- 保留现有 `LICENSE` 与 Git 历史。
- 不创建 Python 包、`pyproject.toml`、uv 虚拟环境或业务代码。

## 初始化方式

在仓库根目录运行 Speckit 的初始化命令，目标目录为当前仓库，并选择 Codex 作为唯一的 AI 助手集成。初始化完成后，检查生成的目录、模板和命令入口是否存在。

## 工作流

1. 使用 Speckit 创建或更新功能规格。
2. 基于规格生成实现计划。
3. 基于计划生成按依赖排序的任务清单。

## 错误处理与验证

若 CLI 启动失败，先记录完整报错并验证 uv 安装的命令入口与当前执行环境；不手工仿造 Speckit 生成文件。成功初始化后，以 Git 状态和生成目录确认变更范围。
