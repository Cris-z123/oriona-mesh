# 内部模型出口数据契约

本契约约束后端内部 `model_gateway` 与业务服务、Celery worker 及供应商适配层之间的数据边界。
它不是公开 HTTP API，但属于 A5 必须冻结并自动验证的内部接口。

## 调用信封

业务调用方只能提交以下字段：

| 字段 | 规则 |
|---|---|
| call_id | UUID，由网关入口创建或验证 |
| trace_id | UUID，继承当前请求或任务上下文 |
| subject_digest | 用户/租户标识的带密钥不可逆摘要，不得提交原始 UUID 或邮箱 |
| call_type | `embedding`、`query_rewrite`、`rerank`、`generation` |
| content | 当前调用所需的最小内容，进入供应商适配层前必须完成脱敏 |
| options | 与调用类型相关的非敏感参数，不得包含供应商凭证或请求头 |

业务调用方不得指定供应商凭证。供应商、端点、模型和凭证由网关根据服务端配置决定，凭证只
在网络发送边界注入。

配置变量统一使用 Quickstart 定义的 `MODEL_GATEWAY_*` 名称。Embedding 模型默认
`text-embedding-3-small`，Query Rewrite 与 Generation 模型必须显式配置；Reranker 模型为空表示
禁用重排并直接使用 RRF，且不影响应用就绪。各调用超时和最大重试次数同样由对应的
`MODEL_GATEWAY_*_TIMEOUT_SECONDS` 与 `MODEL_GATEWAY_*_MAX_RETRIES` 注入，业务调用方不得覆盖。

## 各调用类型允许内容

| 调用类型 | 允许发送的最小内容 | 禁止内容 | 脱敏失败行为 |
|---|---|---|---|
| embedding | 当前待嵌入片段文本及必要的批次顺序 | 文件名、存储路径、用户/租户原始标识、任务 payload | 不发送；按既定重试后使当前 embed 任务与资料失败 |
| query_rewrite | 用户当前问题及最近三轮必要消息文本 | 会话/消息 UUID、引用快照、文件名、凭证和请求头 | 不发送；回退原问题 |
| rerank | 用户问题、候选片段的脱敏文本及调用内临时序号 | chunk/document UUID、文件名、存储位置、供应商原始响应 | 不发送；回退 RRF 顺序 |
| generation | 用户问题、脱敏 Context Pack、最近三轮必要对话文本和引用临时序号 | 内部 UUID、文件路径、完整任务/引用对象、凭证和请求头 | 不发送；按既定重试后将 assistant 消息收敛为 `cancelled` |

页码、章节等定位信息仅在模型确有生成引用标记需求时以最小结构发送；文件名默认不外发，由
服务端在模型响应后使用临时序号重新关联正式引用。

## 禁止外发与脱敏规则

- 始终删除：密码、访问/刷新令牌、API 密钥、Cookie、Authorization 和其他认证请求头、内部
  绝对存储路径、用户/租户原始标识。
- 统一替换：邮箱、电话号码、身份证件号等个人标识使用本次调用内稳定且不可逆的占位符。
- 禁止建立占位符到原值的持久化或日志映射。
- 脱敏器异常或无法可靠处理禁止数据时必须 fail-closed；供应商适配器不得收到未标记为已脱敏
  的调用对象。

## 供应商适配层前置条件

供应商适配器只接受网关创建的 `SanitizedModelCall`，其中必须携带：

- `sanitization_status = passed`
- 脱敏策略版本
- 调用类型、供应商、模型和超时/重试策略
- 已脱敏内容及非敏感选项

任何缺失或失败状态必须在发起网络连接前拒绝。

## 日志元数据白名单

只允许：`trace_id`、调用 ID、不可逆主体摘要、调用类型、供应商、模型、开始/结束时间、耗时、
状态、错误分类、重试次数、输入/输出 token 数量和载荷字节数。

禁止：请求/响应正文、提示词、用户问题、资料片段、文件名、请求头、凭证、供应商原始错误体、
可逆摘要及脱敏后的正文。

## 验证要求

- 架构测试必须证明只有 `backend/app/infrastructure/model_gateway/providers/` 能导入供应商 SDK、
  LangChain 供应商集成或创建外部模型 HTTP 客户端。
- 四种调用类型都必须通过受控假供应商验证输入最小化、禁止字段删除、个人标识替换和日志白名单。
- 脱敏失败测试必须证明供应商假服务收到零请求。
- 重试、超时和降级测试不得把正文或供应商原始错误写入日志、异常或数据库。
